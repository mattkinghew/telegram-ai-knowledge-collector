# Active Projects — Mobile Setup

Status: `CURRENT`.

Use one on-device List or Dictionary shared conceptually by the two Shortcuts. Do not add a database, API, dynamic backend, or repository copy of real project names.

## Rules

- Keep 3–8 active projects.
- Use short display names that are unambiguous on a phone.
- Do not include every archived, paused, or someday project.
- Do not include client/employer identifiers in screenshots or this repository.
- Update the device menu only when the active list materially changes.

## Setup

1. Copy the structure of `config/example-active-projects.json` privately.
2. Replace fictional names only on device.
3. Paste the same ordered list into `收集靈感到 Obsidian` and `更新專案進度`.
4. Add a final `不連結專案` option only to Knowledge Capture; Project Update requires one project.
5. Test selection with fictional content before using private work data.

## Maintenance

- Weekly or after a project starts/ends: remove inactive names and add only newly active ones.
- Renaming a display name does not migrate old notes; preserve readability manually.
- If the two Shortcuts disagree, update both lists before the next capture.
- Keep `config/example-active-projects.json` fictional and unchanged by private operations.
