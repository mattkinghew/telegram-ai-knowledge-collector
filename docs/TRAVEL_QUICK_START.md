# Travel Quick Start

## Morning

- Open the project dashboard/reference list.
- Choose today’s 1–3 priorities and check the next action for each active project.
- If useful, run `更新專案進度` once with the starting position.

## During work

- After a meaningful change, run `更新專案進度`.
- Record Completed/Current progress and one Next Action; add Blocker/Evidence only when useful.
- Preview, then save. Do not claim completion without evidence.

## When finding useful content

- Share it to `收集靈感到 Obsidian`.
- Write one Insight. Use `快速保存` when speed, privacy, battery, or connectivity matters.
- For images/files, describe what you observed; the Shortcut does not OCR, parse, or upload.
- For video URLs, save your takeaway; do not claim a transcript exists.

## When finishing meaningful work

- Add one concise project update.
- Preserve the Next Action so the next session can start immediately.
- Link only approved, non-sensitive evidence.

## When reporting

- Select explicit updates only.
- Generate a concise draft, check project/progress/next action, then edit manually.
- Never treat a simulator, draft, or sync assumption as completion evidence.

## When offline

- Use Quick Save and local Obsidian notes.
- Do not call AI. Remotely Save may wait for connectivity.
- Confirm sync later; local availability is not proof of remote sync.

## When AI fails

- Choose `保存原始筆記`.
- Source and user text must remain unchanged.
- Retry only after checking connectivity and data-sharing approval; live AI is optional.
