# Travel Quick Start

## Morning

- Keep only two recommended daily entries visible: `語音閃念` and `收集內容`.
- Older capture/project Shortcuts remain installed as fallback when explicit
  structured reporting is needed.

## During work

- Have something to say → run `語音閃念`, speak once, optionally correct the
  transcript, then save.
- Do not answer title, project, Insight, Context, Action, category, or output
  questions.
- Use `更新專案進度` only when the explicit structured fallback is useful.

## When finding useful content

- Share it to `收集內容`.
- Choose only `整理`, `只收藏`, or `取消`. No Insight/Context/Action or manual
  source-category question is required.
- `整理` may optionally choose `一般整理`, `轉短文章`, or `深入建議`.
- URL-only, image, and file references stay raw/pending when source content is
  unavailable; never claim they were summarized.

## When finishing meaningful work

- Add one concise project update.
- Preserve the Next Action so the next session can start immediately.
- Link only approved, non-sensitive evidence.

## When reporting

- Select explicit updates only.
- Generate a concise draft, check project/progress/next action, then edit manually.
- Never treat a simulator, draft, or sync assumption as completion evidence.

## When offline

- Voice: preserve the confirmed transcript with `ai_status: pending`.
- Content `只收藏`: save with `ai_status: none`.
- Content `整理`: save supplied content/reference with `ai_status: pending`.
- Do not call AI or retry automatically. Remotely Save may wait for connectivity.
- Confirm sync later; local availability is not proof of remote sync.

## When AI fails

- Save the full original capture as pending.
- Source and raw text must remain unchanged.
- P1.4 has no automatic retry; live AI remains optional.
