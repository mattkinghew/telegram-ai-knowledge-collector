# Manual-only Work Matrix

Codex has prepared repository examples, validators, mappings, previews, sample payloads, recovery behavior, and test instructions. Estimates are planning ranges, not guarantees.

| Task | Codex can do | User must do | Time estimate | Required before travel | Optional |
|---|---|---|---:|---:|---:|
| Enter Vault identifier | Provide placeholder and validation rule | Enter real ID only on device | 2 min | Yes | No |
| Enter active projects | Provide fictional shape and allowlist rule | Enter private short names on device only if optional voice AI uses them | 3–5 min | No | Yes |
| Build/sync Voice Flash | Provide literal action sheet and offline fallback | Build `語音閃念`, review dictation privacy, and sync if approved | 15–25 min | Yes | No |
| Build/sync Content Capture | Provide literal one-share action sheet | Build `收集內容` and enable approved Share Sheet types | 20–35 min | Yes | No |
| Keep older Shortcuts | Preserve reference build sheets | Keep `收集靈感到 Obsidian` / `更新專案進度` as fallback | 0–5 min | No | Yes |
| Run four P1.4 scenarios | Provide exact scenario and acceptance criteria | Operate devices and record observed result | 20–30 min | Yes | No |
| Verify Remotely Save | Define exact observable result | Confirm approved sync on two devices in Scenario 1 | Included above | Yes | No |
| Configure Make/Gemini | Provide schemas, prompt, field mapping, payload pack | Create private modules/connections and test public-safe content | 30–60 min | No | Yes |
| Paste webhook URL | Provide on-device placeholder and failure path | Paste real URL directly on device | 2 min | No | Yes |
| Run five voice acceptance tests | Provide exact cases and record fields | Operate Siri/Shortcut/Obsidian and record observed evidence | 15–25 min | No | Yes |

Minimum P1.4 travel sequence: enter the private Vault identifier → build/sync
`語音閃念` and `收集內容` → run the four P1.4 scenarios. Older Shortcuts and
live AI remain optional fallback modules.
